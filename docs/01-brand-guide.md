## 05 品牌色彩系统

| 角色 | 名称 | HEX | RGB |
|------|------|-----|-----|
| 主色 | 凯奇红 | `#C1121F` | 193 18 31 |
| 辅助色 | 暖白 | `#F8F5F0` | 248 245 240 |
| 中性 | 深黑 | `#111111` | 17 17 17 |
| 中性 | 浅灰 | `#E5E5E5` | 229 229 229 |

### 使用原则

- 凯奇红为**唯一强调色**，用于 Logo、关键 CTA、重点分隔线，**克制使用**。
- 大面积底色以暖白 / 深黑 / 浅灰为主，营造留白与高级感。
- **禁止**大红大紫铺满、禁止促销式撞色。

## 08–13 实体物料规范（摘要）

- **名片**：正面 `KQ / KEIQI DESIGN / 高端住宅空间定制机构`；背面姓名 / 职位 / 电话 / 微信 / 邮箱。
- **工装**：暖白底，胸前 KQ Logo，背面 KEIQI DESIGN，字体凯奇红。
- **安全帽**：白色，正面 KQ，侧面 KEIQI DESIGN。
- **工地围挡**：顶部 KEIQI DESIGN，中部「设计美好生活方式」，底部「定制设计 / 精工施工 / 健康住宅」。
- **工程铭牌**：项目名称 / 项目经理 / 设计师 / 开工日期 / 预计竣工日期。
- **车辆贴花**：车门 KQ Logo，车尾 `KEIQI DESIGN / Designing Better Living`。
