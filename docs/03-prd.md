## 2. 产品概述

### 2.1 定位
高端住宅空间定制机构官网。服务别墅、大平层、顶层复式、私人会所。

### 2.2 目标用户
| 角色 | 画像 | 核心诉求 |
|------|------|----------|
| 高净值业主 | 30–55 岁，有房待装/改造 | 看到专业度与调性，愿留资咨询 |
| 设计师/项目方 | 内部或合作方 | 展示能力与案例 |
| 运营/市场 | 凯奇内部 | 通过官网 + AI 顾问获客 |

### 2.3 核心价值与差异化
**高端住宅 × 健康住宅 × 日本整体厨卫 × AI设计顾问**（四体系组合，详见品牌手册 V3 §1.2）。

### 2.4 成功指标（北极星）
- 获客：月留资数、AI 顾问对话发起数、报价请求数。
- 品牌：首屏停留 > 30s、跳出率 < 45%、移动端占比适配。

**Projects（案例预览）**

- 深黑底区块，3–4 项：如 `15+ 年定制经验` `200+ 交付案例` `100% 无醛交付`
- 数字 Cormorant 大字号，可点缀凯奇红

**CTA（#contact 锚点）**

### 5.2 PROJECTS（P0）

**目标**：展示案例、支持筛选、引导留资。

**5.2.1 列表页 `/projects`**
- 顶部标题区：区块 `精选案例` + 一句话
- 筛选栏：类型（别墅/大平层/顶层复式/会所）、风格（现代/新中式/极简…）、排序（最新/面积）
- 卡片网格：占位图 + 类型标签 + 案例名 + 面积/户型摘要 + `查看详情 →`
- 分页或无限滚动（首期分页，每页 9 条）
- 空态：`暂无符合条件的案例` + 清除筛选按钮
- 加载态：骨架屏（浅灰块）

**5.2.2 详情页 `/projects/[id]`**
- 图廊：主图 + 缩略图（占位），可切换
- 项目信息：类型、面积、户型、周期、所在城市（脱敏）、四体系标签
- 设计说明：2–3 段（占位文案，调性见 ToV）
- 相关推荐：同类型 3 例
- 底部 CTA：`预约同款设计咨询` → `/contact`
- 404：无效 id 显示「案例不存在」+ 返回列表

### 5.3 AI DESIGNER（P0）

**目标**：用「凯奇AI设计顾问™」降低咨询门槛，前置收集需求。

**入口**：导航 `AI DESIGNER` → `/ai-designer`；HOME 可加入口卡。

**界面分区**
1. 介绍区：标题 `凯奇AI设计顾问` + 说明（设计咨询 / 自动报价 / 户型上传）
2. 对话区：对话气泡（用户右、AI 左），输入框 + 发送
3. 快捷入口：① 开始设计咨询 ② 获取报价 ③ 上传户型

**功能与状态（前端，后端见 Sprint 04/05/06/07/12/13）**
- **对话**：输入 → 发送 → loading（思考中…）→ AI 回复（占位/接 OpenAI）
- **自动报价**：点击 → 展开表单（房型/面积/风格/预算）→ 提交 → 返回估算区间（占位）
- **户型上传**：点击 → 文件选择（图片/pdf）→ 上传进度 → 成功提示（识别见 Sprint 13）
- 错误态：网络失败「请稍后重试」；空输入禁用发送

**文案要求**
- AI 语调遵循品牌手册 V3 §14 ToV：专业、笃定、不推销。
- 禁止「免费」「秒杀」等词。

**按钮总览（AI DESIGNER）**
| 按钮 | 动作 |
|------|------|
| 发送 | 提交对话 |
| 获取报价 | 展开报价表单 |
| 上传户型 | 打开文件选择 |
| 预约真人顾问 | /contact |

### 5.4 CONTACT（P0）

**目标**：留资转化，字段最小化。

**表单字段**
| 字段 | 类型 | 校验 |
|------|------|------|
| 姓名 | 文本 | 必填，≤20字 |
| 手机号 | 文本 | 必填，11位手机号正则 |
| 微信 | 文本 | 选填 |
| 需求类型 | 单选 | 必填：别墅/大平层/顶层复式/会所/其他 |
| 备注 | 文本域 | 选填，≤200字 |

**状态**
- 默认：字段空，提交禁用
- 校验失败：字段下红字提示（不破坏整体克制调性，红字用凯奇红）
- 提交中：按钮 loading「提交中…」
- 成功：替换表单为成功卡 `已收到，顾问将在 1 个工作日内联系您` + 返回首页
- 失败：提示「提交失败，请重试或直接加微信」

**联系信息展示**（右侧或下方）
- 电话 / 微信 / 邮箱占位（来自品牌手册，真实值后续填）
- 提示：`健康不是选配，而是住宅的基础标准。`

## 8. 非功能需求

- **SEO**：每页 `metadata`（title/description/OG）；结构化数据（Organization/LocalBusiness）；`lang="zh-CN"`；中文语义化。
- **性能**：图片 `next/image` 优化；首屏 LCP < 2.5s；字体 `next/font` 自托管无外链。
- **无障碍**：语义标签、焦点可见、对比度达标（深黑/暖白）。
- **安全**：表单防滥用（rate limit/校验）；不暴露内部接口；隐私合规（留资告知）。
- **合规**：商标带 ™；案例脱敏；字体商用授权（见品牌手册 V3 §15）。
